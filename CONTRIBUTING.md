# Contributing

Thank you for looking at **The Attention Ablation Test**.

- **Found a number that does not reproduce?** Open a *Reproduction problem* issue with the command you ran and its full output.
- **Have a question about the design or the data?** Open a *Question* issue.
- **Want to extend the study** (more models, other architectures, other languages)? Open an issue first so we can agree on the protocol before any outputs are scored.

Rules that keep the record trustworthy:
1. Released raw outputs, annotator sheets and keys are never edited. Corrections are added as new files with a note.
2. Hypotheses and scoring rules for any new run are written down before the outputs are scored.
3. Every number in the README must be recomputable by a script in this repository.
